# 灰豆光影引擎 AI 使用手册

适用对象：通过 Windows 图形界面接手操作的 AI。软件版本：灰豆 AI 光影引擎 v7.7.1。验证日期：2026 年 10 月 18 日，America/Los_Angeles。旧机主工作项目：红盐，导演台测试项目：漫剧202610181520；新机独立项目：接手验证-盐湖三镜头-20261018。新机只有文档与证据素材，未恢复旧生成工程。

当前已经跑通主链路：参考图 → MJ、Image 2.5、Nano Banana 2 生图 → 人物素材库 → 剧本拆解 → 角色绑定 → Wan 视频 → 时间线剪辑、配乐及字幕 → MP4 和 SRT 导出。十类添加节点均已列入功能地图；附加功能按下表区分验证深度。不能把这份手册理解成所有模型、所有参数组合均已验收。

## 接手时先读

1. 用户主要使用 MJ 生图。沿用已选参考图和提示词前，先核对目标节点；不要改错已有作品。
2. 用户允许试跑功能；耗时任务确认进入排队或生成即可，记录后继续其他工作，不需要守到完成。
3. 每次生成只提交一次。结果慢、按钮仍可点击或截图延迟，都不是再次提交的理由。
4. 测试优先复用已完成素材；视频先单镜头、低清晰度。批量前确认实际任务数量、模型、画幅、时长及余额。
5. 原图、原视频保留。练习裁切、消除、抠图、删除前，先创建独立测试结果或副本；不要清空用户画布。
6. 不要把“存在音轨”写成“对白正确”，不要把导出 720P 写成源素材具有 720P 细节。
7. 当前没有已验证的公开 API。本文使用桌面操作路径；没有验证在云端安装或运行该 Windows 程序。

## 桌面操作协议

### 选择应用和观察状态

历史验证使用 computer-use 技能及 `@oai/sky`。其他 AI 使用自身实际可用、已授权的 Windows 桌面控制工具，遵守同一观察与确认协议；具体适配见 docs/AI-ADAPTERS.md。只能使用实际返回的窗口、截图和控件；不要复用本次 element_index、截图 id 或屏幕坐标。

识别窗口：标题“灰豆AI光影引擎”；本机进程路径为 `<当前用户 LocalAppData>\灰豆AI光影引擎\huidou-ai-comics.exe`。路径是识别线索，不代表其他电脑同位置安装。

操作循环：捕获窗口截图及可访问文本 → 确认当前模式和目标 → 执行一项动作 → 再捕获确认。弹窗动画常导致第一次截图仍是旧画面；先刷新观察，不要重按生成。

控件树有时会保留被遮挡的背景按钮，甚至隐藏入口。点击调用无报错也不代表按钮实际生效；以弹窗或状态变化确认。节点重叠时优先切换手形平移画布，在空白区域操作；不要靠盲点背景按钮。

新机 `@oai/sky` 同一状态可能返回13×13的TAURI边缘截图和1440×900主截图。坐标必须配合**实际查看的主截图自己的 screenshotId**，不能固定使用screenshots[0]。本轮UIA点击出现位置偏移，采用主截图坐标成功。原生对话框关闭或导入后若持续返回旧画面/空树，重新获取已发现的唯一灰豆窗口并激活，再取状态；不能沿用旧控件索引。

### 原生文件选择器

文件对话框可能没有独立出现在窗口列表，且可访问文本为空。观察文件名输入框与光标，输入完整绝对路径，再按 Enter。取消可用 Escape。不得把当前文件夹猜成下载目录；对话框可能记住上次导入背景音所在的 work 文件夹。

新机原生文件框将 `C:/...` 报为文件名无效，改用 `C:\...` 成功。文件夹选择框输入完整目录后，Enter可能只导航进该目录；用Tab聚焦可见“选择文件夹”按钮后再Enter才确认。UIA焦点可能滞后，以截图中实际光标/选中和按键后的结果核对。set_value超时不证明未写入，先复查字段。

如果点击报“目标窗口不是 huidou-ai-comics”，不要改用系统级盲点或操作其他应用；重新观察，优先键盘取消，恢复目标窗口。

### 画布导航

箭头选择节点，手形平移画布，滚轮缩放，底部“适配视图”找回全局。双击空白处或底部加号、右键空白处可添加节点。新节点常出现在当前画布中心，连续添加容易重叠；先把视口移到空白区域。

连线方向为右侧输出到左侧输入。参考图的蓝色 `@图1` 等标记须与真实连接对应；仅在文字中写“图1”不证明图片已上传。

| 操作 | 快捷键或方式 | 注意 |
|---|---|---|
| 撤销及重做 | Ctrl+Z / Ctrl+Y | 在文本框、修图或时间线中可能作用于不同编辑层 |
| 复制粘贴节点 | Ctrl+C / Ctrl+V | 先确认画布焦点 |
| 编组 | Ctrl+G | 入口说明；未验证复杂组行为 |
| 拖拽复制 | Alt 加拖拽 | 入口说明 |
| 自动连线 | L；反向 Shift+L | 依位置找节点，先核对目标 |
| 素材接生图 | I | 实测连接最近的已有图片节点，**不创建新节点** |
| 素材接视频 | V | 检查最近的视频节点是否为目标 |
| 大图预览 | 双击图片 | 关闭预览后才能操作后面的工具栏 |

## 图片生成

### 标准操作

1. 添加“AI 图片”节点，或选现有节点并展开。
2. 连接参考图、上传、从素材库选，或粘贴可访问的图片直链。
3. 在参考素材舱检查图片张数，并为参考设置用途：角色、姿势、风格、场景或道具。
4. 写主体、造型、动作、场景、光线、构图和不要改变的特征。必要时通过 `@` 菜单引用实际素材。
5. 打开参数，核对模型、画幅、清晰度、数量和高级设置。不同模型重新核对一遍。
6. 点击一次“立即生成”；记录任务状态及余额。结果生成后会出现在独立图片节点中。
7. 打开大图检查角色、肢体、构图、文字及参考一致性；满意后下载和存入对应素材分类。

成功信号：结果节点有实际图片，大图可打开。下载成功信号：按钮显示“已保存”，且本地存在新文件。素材库成功信号：分类中出现记录、能再次被选入其他流程。

### 三种重点模型

| 界面名称 | 本次成功参数 | 提示词与结果经验 |
|---|---|---|
| Midjourney | 4 参考图，auto，2K，×1 | 本次 ×1 返回 4 张，按任务批次理解并观察实际张数 |
| ChatGPT Image 2.5 | 同参考、auto、2K、×1；另四格分镜 | 可以复用参考，但本次神祇样本角形与色调有变化 |
| Nano Banana 2 | 同参考、auto、2K、×1；导演台 16:9、2K | 软件显示名已确认；没有核实底层 Gemini 版本 |

原神祇英文提示词含 `--ar 2:3 --v 7 --stylize 175 --raw --iw 1.3 --no ...`。Image 2.5 和 Nano 的首轮兼容测试原样提交并成功，但不能据此证明理解 MJ 指令。正式跨模型切换时，将所需比例设进 UI，其他要求改为自然语言，去掉不适用的 MJ 尾缀。

参考锁定按钮包括锁角色、锁姿势、锁构图、锁风格。这些是给模型的约束，仍需验收；不能向用户承诺绝对一致。

### 可复用提示词结构

```text
以已连接参考图中的角色为唯一主角，保留面容、角形、发型、服装和主要配色。
画面内容：[一个明确动作]，场景：[地点和时间]。
镜头：[景别、角度、构图]，光线：[方向、颜色、强度]。
材质与风格：[自然语言要求]。
不要新增人物、不要增加文字，避免改变参考中的身份特征。
```

## 素材管理和图片工具

画布节点、生成历史、素材库和磁盘文件是不同对象。成图不会仅因出现在画布上就自动成为人物素材。选中图 → 工具栏“素材库” → 选择人物、场景或道具等分类。导演台“从素材库替换”再选对应记录。

图片工具栏：AI 修图、重命名、复制图片、下载、素材库、更多、连接。更多菜单包含创建图片节点、作为参考创建视频节点、标注、裁剪、切割、旋转及翻转等。先关闭大图预览再操作。原图不要原地破坏；保存新的结果节点便于比对。

### AI 修图

入口：选图 → AI 修图。顶部圈选、框选、涂抹和擦除选区；有笔刷、缩放、撤销、重做、清空选区。右侧模式为局部重绘、智能消除、手动抠图。

局部重绘：选择区域 → 写明确修改要求 → 核对模型与清晰度 → 核对“仅保留选区内修改” → 开始重绘。当前此面板显示 ChatGPT Image 2、2K。界面说明会提取干净局部图处理，不发送画出的选区线。

默认仅把选区内部贴回；关闭限制会贴回包含附近背景的局部区域。检查边缘接缝、文字、光线和几何关系。完成后“保存到画布”创建结果，“下载 PNG”保存；保存和下载本身不再次调用生成。

本次框选四格分镜左上格天空，要求增加一小片粉红色薄云，其他格及地平线、太阳、水面保持不变，生成成功并保存。处理期间工具及关闭按钮会禁用；不要反复点。右半边 1024×2048 区域的 RGBA 像素 MD5 与原图相同，确认这部分没有改变。

手动抠图是“选区保留，外部透明”，不是自动识别人像。已用盐晶矩形区域生成透明版本并保存画布。智能消除也返回并保存了结果，但天空出现明显矩形色块；正式使用需重新调整选区或贴回范围并验收。每个生成版本应单独保存。关闭编辑器即使当前显示已保存，也可能提示放弃未保存版本；确认所需版本已成为独立画布节点或 PNG 后再关闭，不能假定编辑器版本历史永久存在。

## 从图片制作视频

1. 选中已满意图片 → 更多 → 作为参考图创建视频节点。检查自动接入真实图片。
2. 选视频模型、时长、画幅、清晰度。当前观察过 Wan3.0 经济版、极速版、官方 SD Mini、H3、特价 SD；只有经济版完成本次视频测试。
3. 导演指令写一个主要动作、运镜及声音要求，避免把多个场景塞进一个短镜头。
4. 参考素材舱核对图片、音频和视频的实际绑定。当前界面标注容量为图片 10、音频 5、视频 5，具体支持仍取决于所选模型。
5. 生成一次，确认进度开始或任务已提交后记录。结果慢时继续其他工作。
6. 完成后预览，再下载到预设目录。普通画布视频本次通过点击下载才核实落盘，不能据用户习惯笼统保证全部节点都自动保存。

已成功测试指令：白色巨角神祇站在盐湖，缓缓抬头、轻微呼吸，毛发与衣摆随风，镜头从中全景缓慢推近，冷青晨光，风声与盐晶声，无对白音乐字幕。Wan3.0 经济版，10 秒、16:9、720p。实际 1280×720、10.031 秒、AAC 音轨非静音。

视频动作生成成功与声音符合提示词是两次验收。本次没有完成主观声音语义验收。

## AI 创作中心和剧本

左上 AI 创作中心可选通用助手、短剧编剧、生图提示词、视频导演、润色改写、中英互译。内置说明支持上传图片或文档；本次实测短剧编剧。

短剧需求建议明确总时长、镜头数量、人物数量、场景、对白、画幅和输出格式。要求输出镜头表、每镜头图生视频指令、角色场景道具及声音清单。助手回复与导演台项目不是同一份数据，不能把“已回复剧本”写成“已经自动导入拆解”。

本次导演台另行粘贴了 403 字测试剧本《盐湖苏醒》，拆成 3 个 10 秒镜头。对白分别是“这片湖，记得每一次黎明。”“我醒了。”“我会守住这里。”独立剧本位于 examples/盐湖苏醒-三镜头测试剧本.txt。

## AI 剧本导演五步操作

### 导入剧本

添加 AI 剧本导演节点 → 进入导演台。可粘贴正文或上传；界面指南列有 DOCX、TXT、MD、SRT、VTT，上传格式尚未逐一验证。先选择整剧风格、作品类型、画幅。本次为写实电影短剧、短剧、16:9。

按一集制作，先短片段。长剧按集拆分，避免一次塞入大量角色场景。

### 拆分镜头

执行拆解后逐镜检查时长、动作、景别、运镜和对白归属，检查角色名称与别名。成功时导航会显示已拆镜头数和预计总时长。本次识别为三镜头约 30 秒、角色“盐湖守护神”、场景“清晨盐湖浅水”。

### 准备素材

角色、场景和道具独立管理，卡片省略号菜单可从素材库替换、上传、AI 生成、编辑提示词。优先复用已验收人物。全局生图设置供后续资产沿用，但每次生成前仍核对卡片模型参数。

本次角色已用素材库 MJ 人物替换。场景用 Nano Banana 2 生成并写入 PNG，但本轮再次进入时卡片显示“待创建”，不能只凭磁盘文件断言当前绑定有效。此场景图实看含一个穿现代外套的人物，不能直接作为“无人盐湖”正式背景。正式使用应换成正确图，再检查镜头实际参考。

### 生成视频

统一设置视频模型、画幅、清晰度、时长策略、声音策略及并发。每镜头也有独立参数、提示词及参考图。上方“3/3 已绑定真实参考图”只说明每镜头有图，不表示人物与场景都齐全；看每卡缩略图明细。

首轮单独生成镜头 2：Wan3.0 经济版、10 秒、16:9、480P，声音策略“按对白与音色参考生成”。实际自动保存 854×480 视频，当时未固定音色。后续已为角色上传测试音轨，批量提交镜头 1 和 3；提交后进行中 2、已完成 1。镜头1/3已自动保存；新机核验三条均854×480、30fps、约10.031秒，完整解码通过。抽样发现镜头01运镜偏差、镜头02尾段额外文字；声音语义未验。当前导出试片仍不是三镜头完整短剧。

镜头卡及页面有各自滚动区域。鼠标在长提示词上滚动会只滚文本；查看下部引用及声音控件时，把鼠标移到卡片空白或右侧页面滚动条。

“批量生成视频 2”对应剩余两条。本次确认框明确提交 2 个镜头，确认后未生成 0、进行中 2、已完成 1，已完成镜头 2 未重做。批量前检查数量。重复生成按钮说明保留当前成片，但还需要新增任务成本。

### 整理成片

至少有一条完成视频才可进入。点击“导入/刷新第三步镜头”载入完成镜头；当前导航生成视频是第 4 步，该按钮文字仍写第三步，以实际导入功能理解。

**新机迁移限制：**新建导演台可以切到整理成片，但0条已完成时只显示空状态。本轮用原剧本重建3镜后仍为0/3，没有找到将现有MP4作为已完成镜头导入的按钮。画布“上传参考图片/音频/视频”可以导入并播放MP4，但UI说明用途为Wan3.0动作参考；这不等于加入导演台成片。本轮不能据先前迁移建议声称已有三条视频能直接填回时间线。

时间线支持播放、缩放、适应全部、吸附、片段拖动排序、左右移、复制、分割 S、撤销、重做、拖两端青色把手裁切。选中片段可改原声音量、静音与字幕。

移动播放头时拖白色播放头；本次单击标尺未成功定位，拖动才改变时间。分割前确认播放头落在目标片段内，且当前确实选中该片段。

背景音乐：添加本地文件 → 查看音乐轨 → 调整音乐音量。测试使用人工合成的低音 WAV，只用于导入混音功能验证，不是正式配乐。默认音乐音量 20%，原声 100%。

导出选清晰度、转场、是否输出 SRT，再点导出完整成片并选目录。已跑通直接切换和淡入淡出设置。SRT 是独立文件，不代表字幕已烧录进视频。

## 声音的用途与边界

| 用途 | 入口 | 当前结果 |
|---|---|---|
| 视频自身环境声及对白 | 导演提示词及模型声音策略 | 成功生成有音轨视频，语义及口型待验收 |
| 角色默认音色 | 人物素材的默认参考声音；导演台检查绑定及上传角色声音 | 上传及绑定完成，带音色镜头 1 和 3 已自动保存 MP4，实际效果未验收 |
| 音频参考素材 | 上传图片音频视频节点、视频参考舱 | 已查看入口，未验证音频驱动的生成结果 |
| 配乐及原声混音 | 整理成片时间线 | 本地 WAV 导入与成片导出完成 |
| 独立 TTS、音乐或音效生成 | 尚未找到明确入口 | 不得把音频上传功能当作这些能力已经验证 |

未来上传音色应使用用户提供或已授权的声音。旧机 work 目录中“盐湖守护神-测试音色.mp3”是从本次 AI 生成角色试片提取的约 10 秒音轨，仅作功能测试；它没有随仓库单独上传，可从 evidence/media 中镜头 02 的音轨按需重新提取。它并不是录制的人类声音，也不证明软件已有独立 TTS 功能。

声音库完整路径：素材库 → 声音 → 上传声音 → 选本地文件 → 设名称、片段起终点 → 保存。本次保留全长约 10 秒，名称“AI流程测试-盐湖守护神-合成音轨”，声音计数 0 → 1。人物素材卡的“默认参考声音”下拉中选它，MJ 人物已绑定。原生下拉列表若鼠标点击被窗口检查拒绝，可在明确聚焦后用 Down、Enter 选择，不要点别的应用。

导演台已有角色未因素材库后来绑定而自动出现声音。需要在生成视频页面滚到镜头卡最底部，点击实际可见的“检查绑定 / 上传角色声音” → 上传声音 → 选片段 → 确认。确认后所有使用该角色的镜头提示词追加“声音参考 @音频1：盐湖守护神”。本次未改原台词和动作。界面说明 Wan3.0 所有音频参考合计最多 15 秒；多角色时不要把每人的 15 秒误当可同时全传。

## 视频抽帧

现有 AI 视频节点 → 一键抽帧，自动新建抽帧节点并载入该视频。也可通过添加节点 → 视频抽帧 → 导入本地视频。

工具显示时长及尺寸，有导出当前帧、一键导出首尾帧、更换视频和清空视频。本次对 1280×720、10 秒视频执行一键导出首尾帧，出现两个独立图片节点，分别标记首帧、尾帧。它们可再连生图或视频节点。

## 分镜生成节点

它与导演台的剧本拆解是两个入口。添加“分镜生成”，调 R 行、C 列，每格描述景别、角度、人物动作、表情、环境与光影；每格可通过 `@` 引用素材。

本次设置 2×2 四格，分别描述盐湖远景、水面中景、盐晶特写和日出大全景，全部无人。选择 ChatGPT Image 2.5、自动、2K，点击右下紫色生成按钮，输出一张四格图片节点；实际图中有四个画面、黑色格线，没有描述文字，已下载。当前余额 37609 → 37587，本次差额 22 豆仅作为此样本记录，不代表永久价格。

全局高级设置影响分镜风格一致、禁止描述文字、空格推测、复制时忽略 @ 标签、网格预览快捷键及整体比/单格比显示。本文只读观察这些选项，未改变用户偏好。空格推测开启时，空格不一定代表不生成。

## VR360 全景

添加 VR360 → 选择全景图，或填图片直链、连接上游图片。点击 360° 预览，拖动旋转，底部滑块控制视野角度。顶部可输出当前视角、4 宫格参考、12 宫格参考。

## 3D 导演台

添加 3D 导演台 → 进入全屏，等待模型显示。默认两个人物。左侧人物、环境、镜头、高级四类设置；顶部横屏或竖屏；右下导出当前视角、接 AI 生图、接 AI 视频。

专用手册说明：左键旋转视角，滚轮缩放，右键平移；点击人物道具选择后用轴移动或旋转。环境可上传图，投影支持自动、全景 2:1、长图圆柱；黑边接缝先调地面范围与淡出，悬空可调脚底阴影，背景偏暗调背景明暗。高级导出含深度、法线、构图蓝图，尚未逐项实测。

## 常见问题和恢复

| 现象 | 操作 |
|---|---|
| 刚点击后仍是旧画面 | 再取一次状态，等待短暂动画结束，先不要重按 |
| 长时间生成 | 看进行中、失败或历史；记下任务位置，转做其他工作 |
| 失败或异常 | 先读原任务原因并确认状态，再决定重试，记录是否新增任务 |
| 参考图没进入导演台 | 先存素材库，再从角色场景卡替换；检查各镜头实际缩略图 |
| 文件存在但卡片待创建 | 当成绑定未确认，用上传或素材替换修复后重新检查，避免直接重付费生成 |
| 节点互相挡住 | 用手形平移到空白处；新增前留空间，不点击被挡住的背景按钮 |
| 看不到旧节点 | 适配视图或小地图找回；不要误以为被删除 |
| 文件对话框在错误目录 | 在文件名或目录栏输入完整绝对路径 |
| UIA 声称有按钮但无界面变化 | 检查是否隐藏、被遮挡或属于上一状态；以可见反馈判断 |
| 素材一致性差 | 先改参考、用途和首帧，单镜头低成本复核后再扩大 |
| 字幕与对白不一致 | 检查实际音频再编辑 SRT；字幕文本来自剧本不证明语音正确 |
| 全景接缝大 | 检查源图是否真正适合环绕；普通照片能打开也可能严重错位 |

内置新手手册的常见问题仍说最终成片要在外部剪辑软件完成；当前 v7.7.1 已实测内置整理成片可剪辑、配乐并导出。遇到说明和界面矛盾时，优先核对当前可执行结果。
