# 完整指南的完成标准

“完整”指当前版本功能地图有明确覆盖，主要操作可复现、附加工具有真实结果或明确限制；不要求穷举每个付费模型与每种参数组合。

- 每个功能写明用途、入口、前提素材、操作步骤、参数、成功信号、保存路径、常见失败和恢复。
- 未实测、入口、已提交、文件存在、结果已查看、质量通过分别记录，不能混为一谈。
- 图像检查身份、构图、肢体、参考一致性及局部编辑边界。
- 视频检查时长、分辨率、动作、角色一致性、字幕；声音另验台词、音色、口型和环境声。
- 真正完成三镜头故事导出，并核对字幕同步；当前18秒重复镜头练习不计此项。
- Codex 和 Claude 在目标电脑分别完成无付费控制测试，至少一条小样路径和记录交接；其他 AI 适配仅承诺中立协议，未经测试不标“已支持执行”。
- 换电脑用相对证据路径可继续；安装、工程同步和工具缺口有明确说明。
- 已知质量问题保留在清单中，补测后更新，不删除历史证据掩盖问题。
